Extra photographs for the sign-in page, shown one after another.

The page always starts with src/assets/lab-hero.jpg — your own picture, the one
on the right today. This folder is for the EXTRA ones that take turns after it.

Drop a .jpg / .png / .webp in here and it joins the rotation the next time the
frontend is built — no code change. The order is the file name, so 01-, 02-,
03- keeps them in the order you want. Leave this folder empty (as it is now)
and the page shows the single lab-hero.jpg exactly as before, with no rotation.

Use a landscape picture, at least 1600px wide. The left edge of the picture is
faded out and the headline and feature strip are drawn on top of it, so keep
the left third and the bottom strip free of detail.
